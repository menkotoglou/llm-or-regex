# Hand-labelled sets (experiments 5, 7, 9)

One CSV per set, columns: `id,text,label,notes`. `label` is 1 = toxic, 0 = clean.
Address them with the same flag as the big samples: `--sample surge-1k`, `--sample obfuscation`, `--sample identity`, `--sample ood`.

- `surge-1k.csv`     Surge AI toxicity set (2022, 1,000 social-media comments, human toxicity labels), held out from apc's training data.
- `obfuscation.csv`  generated by `scripts/make_obfuscation.py`: every word-list match in the toxic items of a base sample, transformed (l33t, spaced, homoglyph, asterisk, concatenated). Labels unchanged by construction (experiment 7).
- `identity.csv`     generated by `scripts/make_identity.py`: 115 innocuous sentences that mention an identity, all label 0 (experiment 9).
- `ood.csv`          ~200 items from a domain the models have not memorised (scrubbed app logs, or comments you write yourself). Contamination sanity check (experiment 5). Label them yourself, before running any arm, and do not look at the arms' outputs while labelling.

House rule for anything you write yourself: hostility and profanity only. No slurs aimed at a group (sexuality, gender identity, ethnicity, religion, disability), no real people, no political figures. The point is made just as well with "you're an idiot" as with anything worse, and the audience includes the people such examples would target. For clean items, include self-descriptions ("I'm gay and proud of it") so the set also carries the identity check.
