# Notes from preparing the talk

Working notes, kept for the record. They refer to an earlier draft of the talk (v3), whose slide
numbers differ from the final deck, and some of their conclusions were revised later. The measured
numbers themselves live in `results/`, and that is the only place to take a number from.

| file | what it was for |
|---|---|
| `SLIDE-NUMBERS.md` | crib sheet: every measured figure, per draft slide, as the runs finished. The "FINAL" section is the complete one |
| `SLIDE-REWRITES.md` | the two draft slides the measurements broke (the winner flips with the labels; the model never returned prose) and drafts to replace them |
| `SLIDE-10-EXAMPLES.md` | how the on-stage error examples were picked, including the ones rejected under the content rule and why |
| `RUNBOOK.md` | the original step order for running the benchmark, in Greek. The top-level README's "Reproduce" section supersedes it |

Content rule used for every on-stage example: hostility and profanity only. No example that targets
a group, names a real person or a politician, or uses a slur.
